# Counter Script Commands

Run these commands from the repository root.

## `count_action_nodes.py`

```bash
python scripts/counter/count_action_nodes.py \
  --tournament_result_dirs data/main_study
```

## `count_player_matches.py`

```bash
python scripts/counter/count_player_matches.py \
  --agents-config configs/agents/test_agents_6.yaml
```
