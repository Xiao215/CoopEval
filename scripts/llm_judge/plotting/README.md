# LLM Judge Plotting Commands

Every plotting script now infers its inputs directly from `outputs/judge/<run_name>/…`.
Run the commands from the project root and replace `${RUN_NAME}` with your judge
identifier (e.g., `full_gpt5.2`). You can export it once:

```bash
export RUN_NAME=full_gpt5.2
```

All plotting scripts export PNG files.

## Taxonomy Radar

Mechanism averages, per-model, and per-mechanism radars (with color schemes from
`config.py`):

```bash
python scripts/llm_judge/plotting/plot_taxonomy_radar.py \
  ${RUN_NAME} \
  --top-labels 6
```

## Taxonomy Heatmaps

Mechanism/model/game heatmaps with optional value overlays:

```bash
python scripts/llm_judge/plotting/plot_taxonomy_heatmaps.py \
  ${RUN_NAME} \
  --include-number
```

## Mechanism Share Small Multiples

Requires `mechanism_label_differences.csv` (generated by `build_justification_report.py`):

```bash
python scripts/llm_judge/plotting/plot_mechanism_differences.py \
  ${RUN_NAME} \
```

## Mechanism Delta Bars

Single-panel diverging bars showing each mechanism's label-share shift relative
to `NoMechanism`, using the shared mechanism palette:

```bash
python scripts/llm_judge/plotting/plot_taxonomy_delta_bars.py \
  ${RUN_NAME} \
  --top-labels 8 \
  --layout both
```

## Cramér's V Scatter

```bash
python scripts/llm_judge/plotting/plot_cramers_scatter.py \
  ${RUN_NAME}
```

## Model Stack Bars

```bash
python scripts/llm_judge/plotting/plot_model_stack_bars.py \
  ${RUN_NAME} \
```

## Label Density Violins

```bash
python scripts/llm_judge/plotting/plot_label_density.py \
  ${RUN_NAME} \
  --metric classification_confidence \

  --top-labels 8
```

## Label Co-occurrence Network

## Mechanism → Game → Label Sankey

```bash
python scripts/llm_judge/plotting/plot_sankey_flow.py \
  ${RUN_NAME} \
  --top-labels 6 \

```

## Mechanism → Label Treemap

```bash
python scripts/llm_judge/plotting/plot_taxonomy_treemap.py \
  ${RUN_NAME} \
  --formats png html
```

## Additional Notes

- All commands write into `outputs/judge/${RUN_NAME}/figures/<plot_name>/…`.
- Sankey and treemap scripts accept `--formats png html`; PNG is always included
  and PDF is not supported.
- Ensure you have run `build_justification_report.py outputs/judge/${RUN_NAME}` first;
  it creates `mechanism_label_differences.csv` consumed above.
- Adjust optional flags (`--top-labels`, `--models`, `--games`, etc.) to tailor each
  visualization. Refer to the script `--help` output for full parameter lists.
